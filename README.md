# Global-Mobility-Application

## How to Run

1. Clone The Repository:

   ```bash
   git clone https://github.com/yagantiAshok/Global-Mobility-Application.git
   ```

2. Navigate to the project Directory:

   ```bash
   cd Global-Mobility-Application
   ```

3. Create and activate Virtual Environment:
  
   ```bash
   conda create -p us_visa python=3.8 -y
   ```

   ```bash
   conda activate us_visa/
   ```

4. Install required dependences
  
   ```bash
   pip install -r requirements.txt
   ```
